## Important limitations

- The default runtime dataset and theft labels are synthetic demonstration data. A high score from this demo is not proof of real electricity theft.
- The supplied CEEW data is not treated as verified theft-labeled data.
- The federated-learning and differential-privacy/security-aggregation modules are research prototypes, not production-grade formal guarantees.
- The smoke run uses a small dataset and one forecasting epoch; it verifies execution, not production-scale performance or real-world model accuracy.
- Model artifacts generated by a different scikit-learn version may emit compatibility warnings. Install the pinned dependencies from `requirements.txt` in a fresh virtual environment for the closest reproducibility.

## Local run

Follow `run.md`. On Windows PowerShell, set `SMARTGRID_ADMIN_EMAIL`, `SMARTGRID_ADMIN_PASSWORD`, `SMARTGRID_SESSION_SECRET` (at least 32 characters), and `SMARTGRID_COOKIE_SECURE=0` for local HTTP development before launching the API. Do not use demo credentials or HTTP cookie settings in production.
